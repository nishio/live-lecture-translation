# 不確実な認識を翻訳へ渡す方針の実データ比較

2026-10-05、ユーザーが指定したオードリーの実データで、変更前後の日本語訳を実際に生成した。**不確実な行を一律に外すと否定が欠けて逆の意味になる例を確認し、新方式ではその否定を保持できた。** 一方、不自然な反復は一部残った。

## 条件

- 音源は[Audrey Tangの公開講演](https://www.youtube.com/watch?v=4_tge6XJhGA)の全325.567秒。公開者・CC BY表示・変換については[出典と帰属](../../samples/audrey-plurality-seoul-2023/README.md#出典と帰属)を参照。
- [ASR区切り長比較](asr-chunk-duration.md)で生成した15秒条件・1回目の認識62行を、両方式で同一に再利用。新たな録音・認識は行っていない。
- 旧方式はコミット `d2970ab` の不確実な行を翻訳対象から一律に外す実装。新方式は実験時の作業ツリーのsource policy version 1を用い、意味ある不確実な行を理由付きで渡す実装で、ソースのハッシュを集計JSONに残した。この記録のコミットは実装コードの公開や稼働中アプリへの適用を意味しない。旧方式でも不確実な行は周辺文脈として渡り得る。
- 両方式とも `gpt-6.1-sol`、reasoning `low`、service tier `default`。各6要求、計12要求を新規送信し、全件usage確認済み、キャッシュ利用なし。
- 音声60/120/180/240/300/325.567秒の各区切りまでに利用可能な認識だけを渡した。先の音声区間、過去の日本語訳、評価表は入力していない。句読点による文の待機条件、2秒の先読み条件、30秒の待機上限、要求容量は共通。
- 同じ区切りで旧・新を続けて処理し、次の区切りでは順番を逆にした。各条件1回で、モデル出力のばらつきを評価できる反復試験ではない。

これは保存済みASRから日本語への比較である。60秒刻みは統制した音声位置であり、以前の実時間セッションの再現、マイク収録性能、発話から画面表示までの遅延ではない。選別・理由メタデータ・プロンプトを含む変更全体を比較しており、それぞれの寄与は分離していない。

## 結果

| 指標 | 旧方式 | 新方式 |
| --- | ---: | ---: |
| 完了したAPI要求 | 6 | 6 |
| 翻訳対象source ID | 47 | 59 |
| 対象に含む不確実な行 | 0 | 12 |
| 不確実な行の対象除外 | 15 | 3 |
| 保存された訳ブロック | 13 | 12 |
| 1要求の処理時間・中央値（秒） | 8.157 | 9.163 |
| 要求処理時間の合計（秒） | 53.018 | 54.536 |
| usage確認済みAPI費用（USD） | 0.0463735 | 0.0511285 |

両方式とも、計画した対象IDの順序・範囲を満たして最後まで完了した。対象IDの網羅は、個々の意味が正しく訳されたことの証明ではない。新方式は不確実な15行のうち12行を対象に戻し、同じ区間・時刻・本文を持つ重複3行を除外した。時刻だけを理由に不確実となった5行はすべて対象に含まれた。

事前に作成した原文別の評価表と実際の日本語訳を、テキストで照合した。

- **限定を否定する箇所**：旧方式では否定を含む前半が対象から外れ、後半だけが肯定の限定として訳された。新方式では前後を含めて否定を保持した。
- **完全な消失を否定する箇所**：旧方式では当該節が欠落した。新方式では部分否定と後続へのつながりを保持した。
- **行為の試みと成功の区別**：新方式で対象に戻った説明は、行為を試みるという原文の範囲を保ち、成功済みと断定しなかった。
- **数量と時代**：年数・人口・倍率の3主張と、日付・時代の4参照は両方式で保持された。新方式で対象に戻った時刻のみ不確実な5行も、対応する意味が訳に含まれた。
- **残存ノイズ**：反復系列の最初の行と大文字小文字だけが異なる次の行が残り、不確実との注記付きで同じ不自然な内容が2回訳された。3行を除外しても、反復の問題を解消したとはいえない。

原文の誤認識、語の置換、未完の断片は残る。今回の方針は有用な意味を翻訳対象から落としにくくするものであり、ASRを正解に直す機能ではない。誤認識らしい内容を流暢に訳せたことも、音声の正しさの確認とは区別する。

## 費用と限界

今回の追加API費用は **USD 0.097502**。12要求すべてがusage確認済みで、新たな未確定予約はない。既存の未確定予約 USD 0.178775 は保持した。承認済みの1日1ドル上限と同じ共有台帳を使い、予算枠を増やしたり台帳を作り直したりしていない。開発用AIの利用量と電力費用は未測定。

同じ講演の同じ認識に対する各1出力の観察であり、一般的な翻訳精度、誤除外率、聴講中の理解の向上は測定していない。人手の正解文字起こしや聴き直しを正解判定として用いていない。保存済みASRへの意味の忠実さと、実際の音声に対する正しさは別の評価である。

元ASR、凍結した入力、API応答、日本語訳、source ID別の照合表はignored領域に保存した。このページには新しい原文・訳文を転載せず、集計と測定範囲だけを記録する。[集計JSON](uncertain-translation-audrey.json)には入力と実装のハッシュ、要求別の費用・処理時間を保存する。稼働中のアプリや既存セッションの結果は変更していない。
