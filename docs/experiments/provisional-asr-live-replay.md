# 速報を組み込んだAudrey音声の実時間再生

2026-10-05、ユーザーのAPI再実行許可を受け、保存済みの公開講演325.567秒を1倍速で供給し、速報・蓄積する原文・日本語訳・理解支援を同時に動かした。**全段階が完了し、翻訳対象59行を処理できた。ただし、最初の速報公開にはセッション開始から20.167秒かかった。** 3秒という更新設定を初回表示の遅延と扱わない。

音源はCode for Japan公開のAudrey Tangによる「Audrey Tang Remarks in Plurality Seoul, 2023 12 02」。CC BY表示、出典、変換と不確実性の注記は[元サンプルの帰属情報](../../samples/audrey-plurality-seoul-2023/README.md#出典と帰属)を参照。音声、認識本文、日本語訳、APIペイロードはこの記録に含めない。既存の公開テキストサンプルは以前の実行結果のまま保持した。

## 条件

- 入力は16 kHz・モノラル・PCM16、5,209,072フレーム。入力SHA256と実装の同一性は[集計JSON](provisional-asr-live-replay.json)に記録した。
- ローカル認識は準備済みの `mlx-community/whisper-large-v3-turbo`、英語。今回新しく認識し、過去のASR結果は再利用していない。
- 速報は3秒ごとの音声境界で直近最大15秒を認識。別の15秒単位の認識を優先し、蓄積する原文と翻訳入力に使った。遅れた速報は最新の窓にまとめ、重なった速報を原文に連結しない。
- 翻訳60秒・分析120秒の開始間隔、`gpt-6.1-sol`、reasoning `low`、service tier `default`。source policy version 1で意味ある不確実な行を理由付きで扱った。
- 新しい保存先を使い、既存の承認、共有予算・送信範囲台帳、推論ロックを維持した。原音・旧結果と、別の録音・処理セッションは変更していない。

最初の速報は音声0〜3秒の窓で、受付は開始から3.314秒、公開は20.167秒だった。起動時のモデル準備や待機を含む観測であり、個々の要因の時間は分離していない。公開間隔は84速報と22原文の時刻を合わせた隣接105区間の統計で、**最初の20.167秒の待ちを含まない**。速報だけの間隔や各単語の初出遅延ではない。窓受付から公開までの統計は84速報を対象とし、最初の長い待ちも含む。

全22原文区間と84速報窓のPCMが入力の対応範囲と一致し、実行時の保存ソースのハッシュも一致した。速報の時刻・窓・版は順序と因果関係を満たし、速報IDが原文やクラウド入力へ混入していないことを確認した。除外3行は同一区間の不正時刻付き重複で、残る59対象は重複なく訳に含まれ、未処理対象は0だった。

保存結果のプレイヤーでは各速報の実公開時刻の前後と巻き戻しを照合した。画面でも再生位置24秒で速報を確認し、0秒へ戻すと消えることを確認した。この操作確認はブラウザ描画遅延の計測ではない。
