# 文字起こしの区切り長と暫定バッファの比較

2026-10-05、ユーザーの「長さを変えて試す」という指示で、保存済みの公開講演を新しくローカル認識した。15秒固定を最適値として維持する根拠は得られず、短い更新間隔と認識に使う音声窓を分ける方針を評価した。

出典はAudrey Tangのスピーチ「Audrey Tang Remarks in Plurality Seoul, 2023 12 02」、公開者はCode for Japan。元動画のライセンス表示はCC BY（Creative Commons Attribution）で、保存メタデータに版番号はない。本記録は音声をPCM16に変換し、機械認識した結果の集計である。音声・字幕・認識本文は含めない。

## 条件

- 入力：[Audrey Tangの公開講演](https://www.youtube.com/watch?v=4_tge6XJhGA)の全325.567秒、5,209,072フレーム。16 kHz、モノラル、PCM16。入力SHA256は集計JSONに記録。
- Mac：Apple M1 Pro、32 GiB、macOS 15.1.1。Python 3.12.8、MLX 0.32.2、mlx-whisper 0.4.3、NumPy 2.5.3。
- モデル：`mlx-community/whisper-large-v3-turbo`、revision `a4aaeec0636e6fef84abdcbe3544cb2bf7e9f6fb`。英語、temperature 0、前回テキストの引き継ぎなし、初期プロンプトなし。
- 各条件2回。固定区切りは3→5→10→15→30秒、2回目は逆順。最初の15秒で準備し、初期化を含む10.124秒は各条件の計測から除外。
- 既存の認識器と共有推論ロックを使用。別の録音・閲覧プロセスやその保存結果を変更せず、新しいignoredディレクトリへ保存。
- 他のデスクトップアプリは停止していない。1回目の一部にはCPUテストの負荷も重なった。2回目はCPUテスト終了後。厳密に負荷を隔離した性能試験ではない。

これは音声を実際にモデルへ渡したオフライン試験であり、マイク収録、ブラウザ表示、聴講中の理解は測定していない。各呼び出しの処理時間には区間WAVの作成・読込・認識・結果保存を含み、外部の推論ロック待ちは分けた。

## 固定区切りの結果

| 区切り | 1回の処理時間・中央値（実測） | 平均待ち時間（推定、2回の範囲） | 講演全体の合計処理時間（実測、2回の範囲） |
| --- | ---: | ---: | ---: |
| 3秒 | 0.654秒 | 2.152〜2.155秒 | 71.406〜71.769秒 |
| 5秒 | 0.673秒 | 3.169〜3.172秒 | 44.330〜44.533秒 |
| 10秒 | 0.725秒 | 5.685〜5.692秒 | 23.840〜24.070秒 |
| 15秒 | 0.771秒 | 8.238〜8.242秒 | 17.790〜17.892秒 |
| 30秒 | 1.523秒 | 16.298〜16.304秒 | 16.100〜16.172秒 |

中央値は各条件の2回分の呼び出しをまとめて計算した。平均待ち時間は「区間末尾まで音声が届いてから、1つの処理器で順に認識する」モデルに実測時間を当てはめ、無音を含む音声時間で重み付けした値。モデル準備、外部推論待ち、ライブ制御、ブラウザ描画は含まない。各単語の認識成功や、その単語が初めて表示される時刻を測った値ではない。

3秒区切りは推定待ちを15秒の約8.24秒から約2.15秒へ短縮した。処理回数は22回から109回へ増え、合計処理時間は約4倍だが、今回の条件では認識待ちの累積は生じなかった。5秒条件の末尾では、最後の0.567秒分の音声が直前の処理終了より早く到着するため、最大約0.125秒の待ちが推定された。

## 認識内容の比較と限界

正解の人手文字起こしは用意していない。取得済み英語字幕には人名などの誤りがあるため、次の値は**字幕との差**であり、WERや認識精度ではない。字幕と出力を小文字化し、HTML文字参照・アポストロフィを揃え、英数字の単語列にした後、単語編集距離を字幕の639語で割った。数字表記や人名は都合よく修正していない。

| 区切り | 字幕との単語編集距離 / 639語 | 現行ルールで不確実扱いになる出力語の割合 |
| --- | ---: | ---: |
| 3秒 | 10.80% | 11.58% |
| 5秒 | 10.49% | 7.38% |
| 10秒 | 7.82% | 3.53% |
| 15秒 | 14.71% | 23.50% |
| 30秒 | 5.32% | 0.47% |

各条件の2回の正規化後の出力は一致し、表の値も再現した。不確実さの多くはモデルの時刻が入力区間からはみ出すことによる。区切り長が変わると行数や境界数も変わるため、この割合も正しさの尺度にはならない。

事前に選んだ人名・数値・否定表現・対比を含む箇所を、前後の行も含めてテキストで確認した。

- 3秒・5秒では、単語の断片、語句の重複、名前を含む部分の欠落が見られた。短い独立区間を、そのまま確定原文として使う根拠にはならない。
- 15秒では約60秒付近の繰り返しが両回で再現した。10行に繰り返し判定が付き、隣接する同一行の組が4組あった。15秒だけを品質上安全な設定とは扱えない。
- 約192〜200秒では、3秒・15秒条件の否定を含む行が不確実として翻訳対象から除外される。5秒・10秒条件では、その否定は翻訳可能な行に残った。別の否定表現では5秒・15秒条件が同様の影響を受けた。**原文を保存していることと、意味が翻訳入力に残ることは別**である。今回翻訳APIは実行しておらず、日本語訳で意味が逆転したと断定する結果ではない。
- 30秒でも区切りをまたぐ概念の欠落候補があり、長い再認識を自動的に正解とは扱えない。

本文照合は聴き直しによる検証ではなく、全ての意味の正誤を判定したものでもない。字幕、生の認識、比較抜粋はignored領域に残し、ここには集計と観察の範囲だけを記録した。

## 3秒更新・直近15秒バッファの追試

同じ全音声で、音声時刻3秒刻みに、その時点で存在する直近最大15秒を再認識する試験を2回実行した。冒頭の窓は3、6、9、12、15秒と増え、以降は直近15秒を保つ。各回109回の認識を行い、末尾も含めた。別プロセスでの準備時間3.736秒は以下に含めない。

| 指標 | 結果 |
| --- | ---: |
| 1回の処理時間・中央値（実測、2回を集計） | 0.777秒 |
| 1回の処理時間・p95（実測、nearest rank） | 0.832秒 |
| 1回の処理時間・最大（実測） | 1.423秒 |
| 平均待ち時間（推定、2回の範囲） | 2.287〜2.289秒 |
| 講演全体の合計処理時間（実測、2回の範囲） | 86.145〜86.342秒 |
| 単一処理器での最大認識待ち（推定） | 0秒 |

重なった窓を連結して全文評価することはしていない。各スナップショットを独立した暫定版として比較し、全109組で2回の正規化後のテキストが一致した。事前に選んだ重要箇所の時刻と不確実判定も再現した。

- 音声時刻60秒のスナップショットにあった繰り返しは、63秒の版で消えた。
- 120→123秒、258→261秒では、推測した補完や語の途中切れが、後続音声を含む版で修正された。
- 195秒で途中だった否定文は、201秒の版では翻訳対象にできる一続きの行になった。
- 一方、72秒では未到着の数値比較の続きを誤って補完し、その後の版で変わった。窓の古い側が切り落とされることによる悪化もあった。

これらは音声時刻が3〜6秒進んだ版同士のテキスト上の観察であり、画面での修正時間や、聴き直しで確認した精度改善を測ったものではない。暫定版をそのまま確定扱いにできるという結果でもない。

## 判断

**次のライブ実装の候補として、速報は3秒更新・直近15秒の更新可能なバッファを選ぶ。翻訳時には、別途長めの音声で認識を見直して使用する版を固定する。** 単独の3秒区切りとの差は推定平均待ちで約0.13秒だった一方、後続音声による更新が具体的に観察できた。15秒固定の約8.24秒の待ちを速報に課す必要性は、この試験からは認められない。

30秒条件は翻訳用の見直しの候補だが、最適長や正解を保証する値ではない。今回のローリング認識と30秒区切りの再認識の合計処理量を足すと、325.567秒の音声に約102秒の処理となる。これは処理量の単純加算であり、同時運転、速報の優先制御、クラウド生成を含めた遅延の実測ではない。

この比較試験の時点では比較ツールのみを実装し、ライブ既定値は15秒のままだった。その後、[独立した速報表示](../../wiki/provisional-asr.md#implemented-provisional-display)を本体と保存結果の再生画面に組み込んだ。速報は3秒更新・直近最大15秒で、音声範囲・版・実際の公開時刻を保つ。既存source IDの本文へ上書きせず、翻訳は別の15秒単位の原文を引き続き使う。安定した部分の統合と翻訳前の再認識は未実装である。この表の待ち時間は過去の計算値のままで、組み込み後の実測値には置き換えない。録音全体・会場音・長時間運用での一般的な最適値を示す結果ではない。
