# 同梱Audreyデモ

約5分26秒の講演音声と、原文・日本語訳・要点・概念説明の生成済みデータです。リポジトリのルート（デモZIPでは展開したフォルダ）で次を実行します。

```sh
./demo.command
```

ブラウザの「▶再生」を押すと、記録当時の時刻に合わせて音声と表示が進みます。一時停止・巻き戻し・先頭からの再生ができます。約5分26秒の音声が終わった後も、最後の処理結果が届く約5分50秒まで表示が進みます。終了はターミナルでCtrl+Cです。

Python 3.9以上だけを使い、追加パッケージ、Swift、音声認識モデル、APIキーは不要です。再生中に録音・推論・クラウドAPI通信は行いません。`./demo.command --check` で起動せずに検査、`./demo.command --no-open` でブラウザを開かずURLを表示できます。Mac以外ではPythonから直接起動できますが、実画面の確認はMacで行っています。

```sh
python3 -S audio-array/lecture_demo.py --session samples/audrey-plurality-seoul-2023/demo/session --audio-file samples/audrey-plurality-seoul-2023/demo/audio.wav --port 0 --open
```

## 収録内容

- `audio.wav`: 元の録音から変換した全長325.567秒、16 kHz・モノラル・16 bit PCMの音声。
- `session/`: 再生に必要な原文62行、速報87件、翻訳20結果、分析6結果と表示時刻・状態・集計値を選別したデータ。
- `manifest.json`: 再生用ファイルのサイズとSHA-256。
- `provenance.json`: 出典、生成条件、変換内容と測定の範囲。

2026-10-06の実行では、速報3秒・翻訳15秒・分析60秒の設定で、翻訳対象59行すべてを処理しました。1:20〜1:28付近では、翻訳と要点整理が同時に生成中になり、整理を待たず新しい訳が届きます。初回の訳と分析はキャッシュです。HTTP 503の失敗6件と再試行による復旧も記録通りに再生します。失敗表示が現れても、再生中のAPI通信ではありません。

認識・翻訳・説明は未校正です。不確実な原文や誤りを修正せず保持しています。元の絶対時刻はセッション開始からの相対秒へ変換しましたが、公開の順序や待ち時間を短縮していません。元データの私的パス、キー、API送受信原本、キャッシュ、台帳、実行時ソースのコピーは含みません。

元の生成時の確認済みAPI費用はUSD 0.1727353、未確定予約はUSD 0.56391です。この再生に費用はかかりません。これらは生成時の集計で、総請求額や翻訳品質の保証ではありません。
